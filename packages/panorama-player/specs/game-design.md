# Web 纯前端剧情游戏设计大纲

## 项目定位

暂定名：《环景心动计划》

类型：Web 纯前端、第一人称、360 度全景互动剧情恋爱游戏。

核心体验：玩家站在剧情场景中央，通过拖拽/陀螺仪环视全景图，阅读对话，点击场景热点，做出选择，推动与不同成年女性角色的关系线。整体氛围参考都市恋爱互动剧的爽感和多线分支，但采用原创人物与原创故事。

视觉 thesis：电影感都市恋爱，全景空间像一段可环视的真人互动剧，情绪温暖、精致、轻微暧昧但不露骨。

交互 thesis：

- 视角即叙事：重要人物和线索分布在玩家四周，转动视角才会发现完整信息。
- 选择即关系：选择不只是加好感，还改变信任、边界感和事业线状态。
- 回忆即收藏：已解锁的全景场景进入回忆相册，可重新观看关键节点。

## 技术方向

- 框架：React + TypeScript + Vite。
- 全景展示：Three.js 或 React Three Fiber，将 2:1 equirectangular 全景图贴到反向球体内侧。
- 数据驱动：剧情、对话、选择、条件和效果全部放在 JSON/TS 配置中。
- 存档：localStorage，支持自动存档、章节存档、重置路线。
- 纯前端：无后端依赖，后续可直接静态部署到 Vercel/GitHub Pages。

## 首屏与界面

游戏打开后直接进入主菜单或最近存档，不做营销式落地页。

主游戏界面：

- 全屏 360 度全景作为唯一主视觉。
- 底部为半透明对话层，显示说话人、对白、旁白。
- 右侧或底部弹出选择按钮，最多 3 个主选择，移动端改为底部抽屉。
- 角落放置小型状态入口：存档、关系、回忆、设置。
- 热点使用低调光点或轻微呼吸圈提示，点击后触发额外台词、物品或隐藏选择。

## 基础玩法循环

1. 进入剧情节点，加载对应全景图、BGM 和初始对白。
2. 玩家环视场景，发现人物、物品或视线热点。
3. 对话推进到选择点。
4. 玩家选择回应、行动或沉默。
5. 系统更新角色关系值、隐藏标记和章节变量。
6. 根据条件进入下一节点、支线节点或结局节点。

## 关系系统

每位角色维护三类数值，避免单纯堆好感：

- `spark`: 心动感，代表浪漫吸引。
- `trust`: 信任感，代表能否进入深入剧情。
- `boundary`: 边界感，过低会触发误解，过高会保持距离。

全局状态：

- `career`: 主角事业状态。
- `integrity`: 真诚度，影响最终是否能进入成熟结局。
- `stress`: 压力值，过高会进入逃避/失败节点。
- `memoryFlags`: 已发现的热点线索与回忆。

## 选择设计

选择分为四类：

- 情绪选择：安慰、调侃、直球、沉默。
- 行动选择：帮忙、追问、离开、承担后果。
- 观察选择：点击全景热点，获取隐藏信息。
- 路线选择：章节后期决定是否进入某一角色路线。

每个选择应有即时反馈，例如角色表情台词、镜头焦点变化、音效或关系状态短提示。

## 章节结构

计划做 1 条主线、6 条角色线、1 个独立成长线、1 个群像同行隐藏结局。

- 序章：主角低谷，被迫接手一场沉浸式品牌项目，意外卷入几位女性的人生交集。
- 第一幕：相遇与误会，建立六位角色的第一印象。
- 第二幕：合作与暧昧，玩家在事业压力与关系选择中推进。
- 第三幕：危机与坦白，旧债、误会、商业竞争和个人创伤爆发。
- 终章：根据选择进入不同结局。

## 角色路线

所有角色均设定为 22 岁以上成年人。

- 林知夏，27 岁，品牌策略顾问。知性、克制、观察力强，路线主题是信任与野心。
- 祁蔓，24 岁，舞蹈教练兼短视频创作者。明亮、直接、行动派，路线主题是热烈与自我证明。
- 苏晚晴，26 岁，咖啡店主兼心理咨询进修生。温柔、洞察、慢热，路线主题是疗愈与坦诚。
- 夏若璃，23 岁，独立游戏主播。机灵、直球、胜负欲强，路线主题是陪伴与勇气。
- 程安雅，29 岁，律师。成熟、锋利、原则感强，路线主题是边界与责任。
- 阮星遥，25 岁，天文馆策展人。浪漫、疏离、想象力丰富，路线主题是理想与现实。

## 结局类型

- 角色真爱结局：与单一角色达成高 `spark`、高 `trust`、健康 `boundary`。
- 事业同行结局：主角完成项目，与多位角色保持清晰边界和合作关系。
- 独立成长结局：没有进入恋爱线，但解决债务/项目/自我逃避问题。
- 遗憾结局：关键节点缺乏真诚或压力失控，关系错过。
- 群像隐藏结局：所有人重要心结都被玩家处理，最终以团队和朋友关系完成展演，不做强制后宫。

## 内容边界

- 画面可表达都市吸引力、时尚、性感、暧昧和亲密距离。
- 不做露骨性内容、裸露、强迫、未成年暗示或不健康控制关系。
- 全景提示词统一写明“成年女性”“电影感”“非露骨”“无裸露”。
- 剧情强调同意、尊重、边界和玩家选择后果。

## 后续开发模块

- `StoryEngine`: 读取剧情节点、执行条件判断、更新状态。
- `PanoramaViewer`: 加载 360 全景图，支持鼠标拖拽、触摸拖拽和移动端陀螺仪。
- `DialogueBox`: 对白、旁白、自动播放、历史记录。
- `ChoicePanel`: 条件选择、限时选择、选择预览。
- `HotspotLayer`: 全景坐标热点、可发现线索、人物互动。
- `RelationshipPanel`: 六位角色状态和路线倾向。
- `MemoryGallery`: 已解锁全景与关键台词回放。
- `SaveSystem`: 自动存档、手动存档、导入导出。
