# Web Panorama Story Game Specs

本目录用于先审阅剧情、功能与素材生成方案，确认后再进入开发。

- [game-design.md](./game-design.md): 整体玩法、前端功能、视觉与交互设计大纲。
- [story-outline.md](./story-outline.md): 原创剧情框架、角色设定、章节分支与结局。
- [panorama-prompts.md](./panorama-prompts.md): 各剧情节点对应的 360 度全景图生成提示词。

创作原则：借鉴都市恋爱互动剧的多线叙事、好感选择和沉浸式第一视角结构，但角色、剧情、场景和台词均为原创，不复刻现有作品的具体人物与桥段。
